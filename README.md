A tiny Node 22 program (stdlib only, no dependencies) that writes a single forecast line for the invented city of Frostwick to `/output/entry.txt` — a weather report where the snow itself is stuck in bureaucracy.

```
Forecast, Frostwick: 12 cm of snow refuses to melt until Form 27B is signed; clerk Edna stamps it denied.
```

## Run

```sh
~/workspace/makefun/node22/bin/node main.ts
```

The entry is written to `/output/entry.txt`.
